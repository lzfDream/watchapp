## 6. 经验

- 从 WSL 调 Windows 程序必须用绝对路径：系统目录不在 PATH，直接按裸名调用找不到。
- `Get-AppxPackage -AllUsers` 在非管理员会话下报 `Access is denied`，改用当前用户作用域即可。
- winget 首次运行要同意 msstore 源协议；加 `--accept-source-agreements` 可静默跳过。
- Windows Python 的安装位置因机器而异，不要照搬另一台机器的路径。
- `apt-mark showmanual` 对 WSL 基础镜像里的包也会列出，不能当成"我装的"。

### 7.3 过程中的问题与经验

- **下载被截断**：本机网络从部分站点拉大文件会随机中断，`content-length` 与实际接收不一致
  （Everything 三次分别只收到 235K/185K/491K，声明 1906504）。用户手动下载后哈希才对上。
  **教训：下载后必须比对声明大小与 SHA-256，不能只看命令退出码。**
- **下载校验**：VS Code 用官方 API 的 `sha256hash` 校验一致；Everything 用官方校验文件一致；
  7-Zip 作者不做代码签名、官方也不发哈希，只能靠官网直链 + 大小核对。
- **Everything 以服务方式运行**（LocalSystem、自动启动），非提权会话 `Stop-Process` 报
  `Access is denied`，必须由用户手动停服务。升级后服务未能自动拉起同样需要提权，
  **用户需手动 `Start-Service -Name Everything`，否则搜索索引不会工作。**
- **便携 zip 可能多一层目录**（如带版本号的子目录），直接复制通配符会套娃，必须先下钻。
- **`code.cmd` 在 WSL UNC 路径下不可用**（CMD 不支持 UNC 当前目录）；`Code.exe --version` 会以 GUI
  进程运行且不退出，不能用作验证手段。改用文件版本 + 注册表 + 扩展计数交叉验证。
- PowerShell 枚举与字符串拼接要写成 `"$($s.Status) | ..."`，否则报枚举转换错误。

公开模板根下的**具体路径**、**硬件型号**、**主机名**它都发现不了。写记录后必须人工复核一次：
凡是能定位到"具体这台机器"的信息，一律用模板或文字描述替代。
